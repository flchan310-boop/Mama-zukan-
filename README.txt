ママ図鑑 - GitHub Pages公開用（初期データ空版）

この版の特徴
- アプリ本体だけをGitHub Pagesへ公開する想定です。
- 初期キャラクターデータは一切入っていません。
- 名前・設定本文・画像など、追加した内容はそのブラウザのIndexedDBへ保存されます。
- GitHub上のHTML / CSS / JavaScriptには、追加したキャラクターデータは書き込まれません。

機能
- キャラ一覧 / 検索
- 人物ごとの設定セクション
- 基準画像・ギャラリー
- 更新履歴
- 完全設定をクリップボードへコピー
- JSONバックアップ / 復元
- ブラウザ内のIndexedDBへ保存

GitHub Pagesへ置く手順
1. GitHubで新しいリポジトリを作ります（例: mama-zukan）。
2. このフォルダの中身をリポジトリ直下へアップロードします。
   index.html が一番上の階層にある状態にしてください。
3. GitHubのリポジトリで Settings → Pages を開きます。
4. Source を Deploy from a branch にします。
5. Branch を main、Folder を /(root) にして Save。
6. 公開されたURLをSafariで開きます。
7. 必要ならSafariの共有メニュー →「ホーム画面に追加」でアプリ風に使えます。

重要な注意
- GitHub Pages上のアプリ本体は公開されます。
- ただし、この版には最初から個人のキャラクター設定は含まれていません。
- ブラウザ内に入力したデータは、その端末・ブラウザ側に保存されます。
- Safariのサイトデータ削除、端末故障、ブラウザ変更などで消える可能性があります。
- 大事な設定は定期的に「JSON書き出し」でバックアップしてください。
- 別端末へ移す場合は、書き出したJSONを新しい端末で読み込んでください。
